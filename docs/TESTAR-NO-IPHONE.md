# Guia para celular

As instruções foram reunidas no [guia para iPhone e Android](TESTAR-NO-CELULAR.md).

Ele mostra como abrir pelo link, pesquisar pelo nome na tela inicial, consultar as 746 entradas do Siglário dentro do app, abrir os PDFs originais, voltar pela aba ou pelo ícone do aplicativo, salvar os arquivos, adicionar o aplicativo à tela inicial e testar em ambos os sistemas. Para o responsável pela hospedagem, também explica como atualizar o mesmo projeto da Cloudflare com o pacote v14, preservando o endereço e o QR Code. Este endereço antigo foi mantido para preservar os links existentes.
